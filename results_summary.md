# Results Summary

## Project Goal

The goal of this project was to demonstrate how continuous monitoring can improve Third-Party Risk Management compared to static vendor assessments.

## Static TPRM Weakness

A traditional TPRM program may review vendors only during onboarding or periodic audits. This can miss risky activity that happens between review periods.

## Continuous Monitoring Advantage

The continuous monitoring model detects vendor activity as it occurs. This improves visibility into access misuse, privilege escalation, delayed offboarding, and anomalous behavior.

## Example Findings

The simulation identified several high-risk events:

- A vendor attempted privilege escalation.
- A vendor accessed payment-related systems.
- A terminated vendor still had access.
- A vendor had delayed offboarding.
- High-access activity occurred with anomalies.

## Target Breach Connection

The HVAC vendor scenario demonstrates how weak third-party access monitoring can create serious cybersecurity risk. In the Target breach, attackers used third-party vendor access as an entry point and moved through internal systems.

## Conclusion

This project supports the idea that TPRM should move beyond static questionnaires and periodic reviews. Continuous monitoring, access control enforcement, auditing, and lifecycle management can improve vendor risk visibility and reduce cybersecurity and compliance exposure.
